SQL for Data Analysis

## Project Overview
This project is part of my Data Analyst Internship. The objective is to use SQL queries to extract, analyze, and manage data from an E-commerce database.

The project uses MySQL to perform data analysis and generate meaningful insights from customer, product, and order information.

## Tools & Technologies
- MySQL Workbench 8.0 CE
- MySQL
- SQL

## Database Name
`ecommerce_analysis`

## Database Tables

The database contains four main tables:

1. **Customers** – Stores customer details such as customer ID, name, and city.
2. **Products** – Stores product information, category, and price.
3. **Orders** – Stores order details, customer IDs, order dates, and order status.
4. **Order_Items** – Stores products included in each order and their quantities.

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- Aggregate Functions (COUNT, SUM, AVG)
- Views
- Indexes
- NULL Value Handling using COALESCE

## Project Objectives

- Retrieve data from database tables.
- Filter and sort records.
- Calculate total sales and average values.
- Analyze customer and product information.
- Combine data from multiple tables using joins.
- Create views for simplified data access.
- Improve query performance using indexes.

## How to Run the Project

1. Install and open MySQL Workbench 8.0 CE.
2. Connect to your MySQL server.
3. Open the provided SQL script.
4. Execute the script using the lightning button.
5. Refresh the Schemas panel.
6. Open the `ecommerce_analysis` database.
7. Run the queries and check the output.

## Expected Outcome

This project demonstrates practical SQL skills, including database creation, data retrieval, data filtering, joins, aggregation, subqueries, views, and basic query optimization.

## Conclusion

Through this task, I learned how to work with an E-commerce database using MySQL and how to apply SQL queries to analyze data and generate useful business insights.
